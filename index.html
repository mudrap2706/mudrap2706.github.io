Data Management & Engineering

Toronto Bicycle Thefts: End-to-End Data Pipeline & BI Dashboard

Open in GitHub

Challenge: Ten years of open municipal crime data (39,000+ records) needed to move from raw CSV to a live, explorable analytics layer usable by non-technical stakeholders.

Solution: Built a streaming-to-warehouse pipeline: Kafka/ZooKeeper ingestion on EC2, a six-stage Python/pandas ETL layer, S3 + RDS MySQL for storage and analytics, 15 hand-written SQL queries with pre-aggregated views, and an Amazon QuickSight dashboard with geospatial and time-series drill-downs.

Impact & Results:

  • Designed full data lifecycle: ingestion, cleaning, warehousing, and BI-layer modeling
  • Surfaced actionable patterns, including theft concentration by location type and citywide recovery-rate trends
  • Built for non-technical exploration, translating a raw open dataset into stakeholder-usable insight
